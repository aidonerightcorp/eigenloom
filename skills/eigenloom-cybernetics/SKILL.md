# EigenLoom Cybernetic Engine Workflow

Use the `eigenloom_*` tool suite whenever decomposing composite objectives, auditing outputs with independent verification, diagnosing spectral health, or compiling recurring symbolic rules into fast local operator stacks.

## Recommended Operating Sequence

1. **Calibrate Reasoning Effort (`eigenloom_calibrate_effort`)**
   - Estimate Expected Value of Sample Information (`EVSI`), select the appropriate `Matryoshka` slice dimension (`16`, `32`, `64`, or `128`), and check whether human disambiguation has positive net information value before expending deep compute.

2. **Decompose Into Interface-Contracted Subtasks (`eigenloom_fission_dag`)**
   - Split multi-stage objectives into content-addressed DAG subtasks backed by local profile-scoped SQLite WAL storage.
   - Review any minimum-entropy disambiguation questions surfaced by `human_attention_and_escalation_engine`.

3. **Acquire Atomic Fencing Leases (`eigenloom_claim_and_fence`)**
   - Claim a subtask with compare-and-swap fencing (`fencing_stamp` and monotonic `fencing_version`) before acting as `maker`.
   - When a subtask is already `verified` by an independent `checker`, reuse the cached verified result directly.

4. **Record Independent Verification (`eigenloom_verify_record`)**
   - Always enforce `maker_id != checker_id`. Never verify an artifact with the same actor identity that produced it.
   - Recording a verification updates `Contextual LinUCB` (`Recursive Woodbury` inverse covariance), `Dawid-Skene` posterior consensus, and `EigenTrust` stationary reputation simultaneously.

5. **Compile Recurring Patterns Into Portable Cartridges (`eigenloom_compile_cartridge`)**
   - Lower verified rule tables or input-target traces into variable-depth `FiLM` + `MoLoRA` residual operator stacks with confidence-margin early exit across `safetensors`, `wasm_base64`, `wat`, `wgsl`, `c99`, `sql`, or `python`.

6. **Inspect & Adapt Weight Geometry (`eigenloom_analyze_spectrum`, `eigenloom_surgical_edit`, `eigenloom_coupling_step`, `eigenloom_morphism_transfer`)**
   - Measure Marchenko-Pastur noise edges, Roy-Vetterli effective rank, power-law tail exponents, and Wanda saliency before applying `svd_nullspace`, `lora_xs`, `recursive_woodbury`, `procrustes_align`, or `hopfield_write` surgical updates with `0.0` anchor drift.
   - Advance multi-timescale co-evolution and zero-token `Successive Halving` configuration exploration via `eigenloom_coupling_step`, and inspect live telemetry via `eigenloom_manifold_status`.
